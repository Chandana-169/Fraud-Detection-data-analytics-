# Day 16 — Autoencoder

## Objective
Explore deep-learning-based anomaly detection for fraudulent transactions.

## Work Completed
- Set up TensorFlow and Autoencoder models.
- Trained on normal transaction data.
- Calculated reconstruction errors for validation and test data.
- Selected anomaly thresholds and evaluated fraud detection performance.

## Output
Autoencoder reconstruction error was used as an additional unsupervised fraud signal.
