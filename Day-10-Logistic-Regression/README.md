# Day 10 — Logistic Regression

## Objective
Build a baseline supervised fraud detection model using Logistic Regression.

## Work Completed
- Trained Logistic Regression models for the four datasets.
- Evaluated validation Precision, Recall, F1, and PR-AUC.
- Optimized decision thresholds using validation data.
- Evaluated the frozen thresholds on the test sets.

## Output
Logistic Regression provided a strong baseline, with dataset-specific thresholds selected for fraud prediction.
