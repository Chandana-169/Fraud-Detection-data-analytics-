# Day 25 — Kafka / Streaming Pipeline

## Objective
Build a prototype for streaming transaction processing and fraud prediction.

## Work Completed
- Created a streaming producer and consumer workflow.
- Processed transactions sequentially through an in-memory queue.
- Tested mixed normal and fraudulent transactions.
- Evaluated streaming predictions using Precision, Recall, and F1.

## Note
The current implementation is a queue/threading-based streaming prototype and is not a deployed Kafka cluster.

## Output
The prototype demonstrated the flow of transactions through prediction and alert generation.
