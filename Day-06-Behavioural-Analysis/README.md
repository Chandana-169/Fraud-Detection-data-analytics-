# Day 06 — Behavioural Analysis

## Objective
Analyze transaction and customer behavior associated with fraudulent activity.

## Work Completed
- Examined fraud rates across transaction categories.
- Analyzed login-attempt behavior.
- Compared numerical characteristics of normal and fraudulent transactions.
- Investigated customer, location, and KYC-related patterns.

## Output
Behavioral patterns such as increased login attempts and transaction characteristics were identified as useful fraud signals.
