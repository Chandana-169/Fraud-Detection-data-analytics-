# Day 15 — Isolation Forest

## Objective
Use unsupervised anomaly detection to identify potentially suspicious transactions.

## Work Completed
- Trained Isolation Forest models without relying on SMOTE-balanced data.
- Generated anomaly scores and fraud predictions.
- Evaluated validation performance using Precision, Recall, and F1.

## Output
Isolation Forest provided an anomaly-based fraud signal for comparison and later hybrid risk scoring.
